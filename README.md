Sales Dashboard | Power BI

An interactive sales analytics dashboard built with Microsoft Power BI
to visualize sales, profit, production cost, freight, order quantity,
product performance, and time-based trends.

Overview

This project presents a Power BI dashboard designed for sales and
business performance analysis. The dashboard combines KPI cards, charts,
slicers, and product-level analysis to make sales information easier to
explore and interpret.

Dashboard Highlights

The dashboard provides visual analysis of:

Total quantity

Total profit

Total freight percentage

Profit percentage

Production cost by month

Profit and order quantity by quarter

Profit by weekday

Product-level sales amounts

Month-based filtering

Product filtering

Key Visualizations

KPI cards for major sales metrics

Monthly production-cost analysis

Quarterly profit and order-quantity visualization

Weekday profit comparison

Product-level sales analysis

Interactive month and product slicers
